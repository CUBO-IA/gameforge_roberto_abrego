# Assets

Este proyecto no incluye assets binarios externos.

- Los tiles, personajes, enemigos, cofres, hoguera y altar se dibujan con
  primitivas de Pygame CE en `game/render/`.
- Los sonidos se sintetizan en memoria en `game/render/audio.py`.
- La fuente es la fuente por defecto de Pygame CE.
- La configuración de balance vive en `game/data/config.json`.

Si en el futuro se añaden assets, deben registrarse aquí con origen, autor,
licencia y versión, y no deben copiarse sin permiso compatible.
