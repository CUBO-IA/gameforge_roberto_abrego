# Directiva global

## Propósito
Construir un RPG 2D de alcance incremental que demuestre capacidad de los agentes para diseñar, implementar, integrar, depurar y probar un producto jugable.

## Principios
1. Primero vertical slice; después expansión.
2. Simplicidad explícita antes que abstracciones prematuras.
3. Python es el lenguaje principal; las dependencias nativas se permiten cuando aportan valor medible.
4. No confundir cantidad de código con calidad.
5. Toda funcionalidad debe tener un criterio de aceptación observable.
6. Los sistemas deben poder probarse sin abrir una ventana cuando sea posible.
7. Las decisiones importantes deben registrarse.

## Alcance inicial
Incluye ventana, input, escena, mapa pequeño, jugador, colisiones, interacción, inventario mínimo y guardado/carga.

Fuera del primer hito: mundo abierto enorme, multijugador, modding, crafting complejo, árboles de diálogo extensos, generación infinita y online.

## Calidad
- Tipado gradual en interfaces importantes.
- Nombres descriptivos.
- Funciones pequeñas y responsabilidades claras.
- Logging útil.
- Errores explícitos.
- Pruebas deterministas para lógica.
- Assets con procedencia y licencia registradas.
