# Referencias de código abierto

Verificar estado, versión, licencia y documentación actual antes de adoptar.

| Proyecto | URL | Uso potencial | Nota |
|---|---|---|---|
| Pygame CE | https://github.com/pygame-community/pygame-ce | Framework 2D | Motor principal propuesto |
| Pygame | https://github.com/pygame/pygame | Referencia histórica/ecosistema | Comparar actividad y compatibilidad |
| Pymunk | https://github.com/viblo/pymunk | Física 2D | Opcional; no necesaria para colisiones tile-based sencillas |
| Tiled | https://github.com/mapeditor/tiled | Editor de mapas | Herramienta de autoría, no motor |
| LDtk | https://github.com/deepnight/ldtk | Editor de niveles 2D | Evaluar formato/exportación |
| PyTMX | https://github.com/bitcraft/pytmx | Carga de mapas TMX | Alternativa si se elige Tiled |

## Política
- No copiar código sin revisar licencia.
- No copiar sprites, música, fuentes ni mapas por el mero hecho de estar en GitHub.
- Registrar versión/tag/commit utilizado.
- Preferir documentación oficial y ejemplos mínimos.
- Revalidar dependencias antes de congelar el entorno.
