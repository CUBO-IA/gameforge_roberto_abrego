# Skill: 2D Physics and Collision

## Elegir solución
- Colisiones de tiles/AABB: implementar de forma sencilla si basta para el juego.
- Física continua, cuerpos, fuerzas y joints: evaluar Pymunk.
- No integrar dos sistemas físicos superpuestos sin razón.

## Requisitos
- Definir unidades y escala del mundo.
- Usar timestep fijo para simulación física cuando aplique.
- Evitar tunneling en objetos rápidos.
- Separar detección de colisión y respuesta.
- Probar bordes, esquinas, paredes y objetos móviles.
