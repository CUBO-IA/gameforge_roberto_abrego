# Skill: Testing and Performance

## Pruebas
- Unitarias para inventario, combate, generación y persistencia.
- Integración para flujo de partida.
- Regresión para bugs corregidos.
- Pruebas con semillas fijas para procedural.
- Pruebas de guardado/carga y archivos corruptos.

## Rendimiento
- Medir antes de optimizar.
- Registrar equipo, SO, resolución, versión Python y dependencias.
- Medir FPS, frame-time p50/p95, RAM y tiempos de carga.
- Separar coste de lógica y renderizado cuando sea posible.
- No usar una cifra aislada como prueba de rendimiento.
